*推导过程：*
PA0 输出 50 Hz PWM 驱动 SG90，OLED 显示角度和脉宽，串口同步打印。
HSE 8 MHz × 9 = 72 MHz，APB1 二分频后 TIM2 仍是 72 MHz。
`Prescaler = 720-1` → 每计数 10 µs；`Period = 2000-1` → 20 ms，即 50 Hz。
所以 1 CCR = 0.01 ms。
每 1 秒角度加 45°，超过 180° 折回，形成 0→180 往复摆动；算出 CCR 后用 `__HAL_TIM_SET_COMPARE`写入。角度变化时才刷新 OLED 和串口。
